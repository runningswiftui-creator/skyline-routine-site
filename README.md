# Skyline Routine 官网

Skyline Routine 的产品介绍与分享页面。

## 页面

- `index.html` — 英文产品主页
- `zh.html` — 中文介绍与分享链接
- `en.html` — 英文介绍与分享链接
- `links.html` — 双语链接汇总
- `help.html` — 跟随语言参数显示使用指南
- `guide.html` — 11 种语言的完整在线使用说明
- `privacy.html` — 隐私说明
- `terms.html` — 使用条款
- `downloads/` — 中文和 English 使用说明 PDF

## 产品信息

- 免费下载，Pro 一次性解锁
- 首次引导、场景包、稍后提醒、轻量模式、会议免打扰、带倒计时的暂停提醒
- 飞行区域：全屏、四分之一或可拖动自定义，单条提醒可单独设置
- 鼠标避让：默认关闭，近/中/远距离；飞机和卡片整体避让
- 无跑道/黑色遮罩，降落后 5 秒提示
- 本周分享卡片
- 本地备份导出与导入
- 18 种飞机，包括轰炸机、侦察机
- 6 种提醒卡片样式
- 7 种主题，包括糖果乐园与二次元
- Pro 多时间段提醒与本周回顾
- 11 种语言
- 提醒数据只保存在本机
